Rates

Columns: property_id,start,end,season,label,nightly,min_nights. One row per date range, start and end inclusive. Season keys: off, shoulder, peak, holiday (colours), or your own.

Availability

Columns: property_id,checkin,checkout,status,note. Check-out is the departure day (not booked). Status: booked, blocked or hold.

To publish
  1. Download the cleaned CSV above (or keep your own file if it passed without errors).
  2. In the GitHub repository, open data/rates.csv or data/availability.csv, click the pencil, paste the new content, commit.
  3. Hosting pulls the commit and the site updates within a minute. No code changes needed.
