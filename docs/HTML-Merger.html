    How it works & format notes

    Add files → arrange with ↑ / ↓ → check the pages you want → Preview all → Save master HTML. Reopen the exported master directly and choose Edit / append files, or use Open master here. Existing pages stay first; new files append to the end. The browser chooses the order of a multi-file selection, so check the numbered list.

    HTML: saved SingleFile layout is shown in isolated iframe srcdoc sections. Embedded assets are kept; external resources cannot load. Scripts, forms, and refreshes are disabled, so interactive or script-dependent pages may differ. Ordinary HTML with separate asset folders is not self-contained; save it with SingleFile first. Images: originals are embedded without conversion or quality loss. Browser-supported images display at their original proportions, scaled to fit. TIFF, HEIC, camera RAW, PSD, and other specialized formats may not preview; download the embedded original to open it in a compatible app. Animated formats stay animated when supported by the browser. TXT: UTF-8 text, with line breaks preserved. PDF: original embedded file, shown by the browser PDF viewer; use its Open / download link if the preview is unavailable. Office: basic text/table preview, with the original file embedded for download. Office formatting, charts, macros, animations, formulas, and other interactive features are not reproduced. XLSX previews use stored cell values. Encrypted or unsupported Office files remain downloadable even if no preview can be made.

    Export contains the selected content and this utility, so you can continue appending offline. Reopening a master restores its included pages. Unchecked pages are omitted from that export. Originals on disk are never overwritten. Very large collections are limited by browser memory; keep backups and split them when needed. Optional compression only replaces large embedded JPEG images when the result is smaller; it never alters standalone image, PDF, or Office originals. Nothing is stored automatically.
